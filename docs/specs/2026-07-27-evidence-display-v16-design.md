# 证据链展示 V1.6 设计

## 目标

降低深研报告“证据链”区域的展示噪音，同时不削弱审计能力。报告继续保留后端清洗后的原始 `evidence` 记录；前端只展示仍然有可追溯摘录或结构化数值的证据。

## 设计

- `report.evidence` 仍是标准的清洗后证据列表。
- 新增面向 UI 的派生视图 `report.evidence_display`：
  - `items`：`quote` 非空的证据条目。
  - `downgraded_count`：因无法追溯到快照证据库而被降级的证据条数。
- 前端优先使用 `evidence_display`。
- 历史报告没有 `evidence_display` 时，前端从 `report.evidence` 计算同样的拆分，因此无需重新生成报告也能改善展示。
- 空的降级证据卡片合并为一条提示，例如 `已降级 N 条不可追溯证据`。

## 边界

- 不使用 cnstock 数据、接口、数据库、Cookie 或报告资产。
- 不修改 BrianHub SSO、网关、AI 配置、数据源密钥或数据目录。
- 不输出买入、卖出、加仓、减仓等直接交易指令。
- 来源证据不足时仍明确标记 `数据不足`。

## 验证

- 单元测试验证 `evidence_display` 保留可追溯证据和结构化数值，并统计被降级的空摘录证据。
- 后端完整单元测试必须通过。
- 浏览器验证“证据链”区域不再展开空降级卡片。
