# V2.2 财报字段追溯设计

## 目标

把已经采集到的 TuShare 财务字段转成研究员可直接审阅的追溯卡片，避免报告只给结论却看不到字段来源。

## 范围

- 新增 `input_snapshot.financial_traceability`。
- 覆盖营业收入、归母净利润、经营现金流净额、应收账款、合同资产、存货、毛利率、净利率、ROE、ROIC、减值损失。
- 每个字段包含 `field_key`、中文名称、期间、数值、单位、来源、数据状态、解释和风险。
- 前端在“可用证据摘要”前展示“财报字段追溯”。

## 约束

- 不新增外部数据源。
- 不读取 cnstock 数据。
- 不改变 BrianHub SSO、AI 配置或数据目录。
- 缺少字段必须标记 `数据不足`。
- 不输出直接交易指令。

## 取舍

减值损失当前快照未采集独立字段，因此 V2.2 先明确展示为 `数据不足`，作为后续接入财报原文或补充 TuShare 字段的稳定缺口。
